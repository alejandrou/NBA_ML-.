# Reviewer Agent Role

Responsibilities:

- Review the diff.
- Check acceptance criteria.
- Run or verify validations.
- Check no live scraping.
- Check no secrets.
- Check no new Peewee.
- Check no `TOT` as real team.
- Check no `player_name` as key.
- Check tests and lint.
- Update `progress/review.md`.
- Mark `changes_requested` or `approved`.
