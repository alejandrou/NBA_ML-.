# F1-011 - CI

## Goal

Add basic CI and review prompt.

## Context

The project needs automated checks that do not scrape live.

## Requirements

- Add GitHub Actions workflow.
- Install with `uv`.
- Run Ruff.
- Run Pytest.
- Add Codex review prompt.

## Acceptance Criteria

- CI never runs live scraping.
- Review prompt checks rate limits, cache, parser purity, secrets, and docs.

## Validation

- `uv run ruff check .`
- `uv run pytest`

## Out of Scope

- Actions that modify code automatically.

## Learning Notes

CI is a safety net, not a replacement for review.
