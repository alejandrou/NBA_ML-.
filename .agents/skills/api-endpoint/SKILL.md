# API Endpoint Skill

Future API rules:

- FastAPI.
- `/api/v1`.
- Read-only initially.
- Pydantic schemas.
- Pagination.
- Filters.
- Router/service/repository separation.
- API never scrapes live.
- API only reads processed DB data.

Do not implement API in Phase 1 unless explicitly requested.
