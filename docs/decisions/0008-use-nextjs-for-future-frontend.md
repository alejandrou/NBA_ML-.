# ADR 0008 - Use Next.js for Future Frontend

## Status

Accepted. The future phase is scoped by ADR 0019, which keeps this stack.

## Context

The owner wants a future web UI for players, rankings, and comparisons.

## Decision

Use Next.js, TypeScript, Tailwind, and shadcn/ui in a future phase.

## Consequences

No frontend is implemented in Phase 1.

## Alternatives Considered

- Server-rendered Python templates: simpler but less aligned with the desired UI.
- Single-page app only: possible, but Next.js gives better routing.
