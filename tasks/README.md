# Task records

`tasks/feature-list.json` is the historical and machine-readable task board
used by repository harnesses. It is not a Codex startup document.

The active Codex task is selected by `docs/ai/CURRENT_TASK.md`; executable,
focused task cards live under `docs/ai/tasks/`. Keep the JSON valid and update
it only when the project workflow or a task explicitly requires it.
