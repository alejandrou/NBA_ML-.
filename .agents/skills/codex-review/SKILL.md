# Codex Review Skill

Review checklist:

- Rate limiter respected.
- No live network tests.
- No secrets.
- No new Peewee.
- SQLAlchemy/Alembic consistency.
- HTML cache used for scraping workflows.
- Parser purity.
- Correct `TOT` handling.
- DB idempotency.
- Data quality.
- Documentation updated.
- Learning changelog updated.
- Feature-list status updated.
- Maintainability.
