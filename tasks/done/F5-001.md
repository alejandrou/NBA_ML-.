# Goal

Implement the offline, read-only FastAPI foundation: `src/nba_data/api`,
`create_app()`, the `/api/v1` prefix, and `GET /api/v1/health` returning
`HealthResponse`.

# Acceptance criteria

- The app factory and health endpoint return 200 with the approved schema.
- OpenAPI contains health and no mutation or unapproved routes.
- Health has no database or network access; all tests are offline.

# Out of scope

Database access, network calls, mutation routes, scraping, migrations,
authentication, other resources.
