# Skills Index

Repo-scoped skills live under `.agents/skills/`.

- `scraping-pipeline`: use for scraper, parser, cache, normalizer, loader, or
  responsible download work.
- `database-migration`: use for SQLAlchemy, Alembic, schema, repository, and
  persistence changes.
- `data-quality`: use for fixtures, tests, validation gates, data quality checks,
  and parser expectations.
- `api-endpoint`: use for future FastAPI endpoint work. Phase 1 does not
  implement API endpoints.
- `feature-engineering`: use for future OVR, rankings, generated metrics,
  player similarity, and ML features.
- `frontend-page`: use for future Next.js, TypeScript, Tailwind, and shadcn/ui
  frontend pages. Phase 1 does not implement frontend.
- `codex-review`: use for code review, PR review, and changeset validation.
